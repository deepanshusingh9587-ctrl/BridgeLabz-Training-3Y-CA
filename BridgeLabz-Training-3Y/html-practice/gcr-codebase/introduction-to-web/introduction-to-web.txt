Assignment 1 - Full Stack Web Development

1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.

Frontend Development:
Frontend development is the part of a website that users can see and interact with. It includes the design, layout, buttons, forms, images, and navigation. Common technologies are HTML, CSS, and JavaScript.

Real-world example: On Amazon, the homepage, search bar, product images, and 'Add to Cart' button are part of the frontend.

Backend Development:
Backend development is the server-side part of a website. It processes user requests, performs business logic, communicates with the database, and returns the required data. Common technologies include Node.js, Java, Python, PHP, MySQL, and MongoDB.

Real-world example: When you place an order on Amazon, the backend verifies payment, checks product availability, stores the order, and sends confirmation.

Full-Stack Development:
Full-stack development includes both frontend and backend development. A full-stack developer can build the complete web application from the user interface to the server and database.

Real-world example: A full-stack developer can build a complete online shopping website with login, product pages, shopping cart, payment system, and database.

Difference:
• Frontend: Visible to users; uses HTML, CSS, JavaScript.
• Backend: Works on server; manages logic and database.
• Full-Stack: Develops both frontend and backend.

3. Describe how a browser requests and displays a web page from a web server.

1. The user enters a website URL in the browser.
2. The browser sends an HTTP request to the web server.
3. The server processes the request.
4. If required, the server retrieves data from the database.
5. The server sends HTML, CSS, JavaScript, and other files to the browser.
6. The browser renders these files and displays the webpage.

5. Explain what a web server is and give examples of commonly used servers.

A web server is software or hardware that receives requests from web browsers and sends web pages or data back to users over HTTP/HTTPS.

Examples:
• Apache HTTP Server
• Nginx
• Microsoft IIS
• LiteSpeed
• Node.js Server

6. Define the roles of frontend developer, backend developer, and database administrator in a project.

Frontend Developer: Designs and develops the user interface.

Backend Developer: Develops server-side logic, APIs, authentication, and connects the application with the database.

Database Administrator (DBA): Designs, secures, maintains, backs up, and optimizes the database.

2. Microsoft Edge – Blink
3. Mozilla Firefox – Gecko
4. Safari – WebKit
