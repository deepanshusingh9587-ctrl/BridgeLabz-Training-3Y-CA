Responsive CSS Cheat Sheet

Filters

Filters change the appearance of an element.

filter: grayscale(100%);

Media Queries

Media queries are used for different screen sizes.

@media (max-width: 700px)

Responsive Design

Responsive design adjusts a page according to screen size.

width: 100%;

Typography

The clamp() function can make text responsive.

font-size: clamp(1rem, 2vw, 2rem);
